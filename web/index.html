⚙️ 推理后端

推理后端

本地 llama.cpp 完全离线；OpenAI 兼容 API 可对接任意服务

API 基地址

OpenAI 兼容接口地址（含 /v1），如 https://api.openai.com/v1

API Key

密钥，仅保存在本机 data/config.json

模型名

使用的模型标识，如 gpt-4o-mini、qwen-plus、deepseek-chat

X-ID（userId）· 可留空

留空即自动匿名登录（无需账号）；填 App 抓包的 userId 则用你的账号（译文进 App 历史）

X-Token（登录令牌）· 可留空

仅存本机 data/config.json；账号令牌约 30 天过期（纯 API 调用不自动续期），过期后重新抓包替换

零配置可用：两个字段都留空时，程序会用本机设备号调 /api/login/anon 换一个匿名账号（接口官方支持，不涉及你的个人账号）。 想用账号身份再填 X-ID/X-Token（抓包 /api/v1/translate 请求头即可）。
该接口单次上限 5000 字（本程序按 3000 字自动分段）；风格支持 9 种固定值 （default / daily_spoken / business_formal 等， 其它自由文本会作为自定义提示词 user_prompts 传递）；术语表也走 user_prompts。

⚙️ 常规设置

默认目标语言

新建翻译使用的默认目标语言

模型文件

从 models 目录下拉选择 GGUF 模型；放入新模型后点「刷新」

省内存模式

模型按需加载，内存占用更低，首次翻译变慢

开机自启

随系统启动自动运行本服务（Windows 注册表）

服务端口

Web 管理界面 / API 监听端口，仅本机可访问

上下文长度（n_ctx）

长文本翻译需加大；越大内存占用越高，修改后重启生效

GPU 层数（ngl）

0=纯 CPU；Vulkan 版设 99 全量 GPU 加速（Radeon 780M 等），改后重启生效

修改端口或切换推理后端后需重启服务生效。
